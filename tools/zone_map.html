Runway zones

Internal tool — writes airports.json

 

Draw

Set trigger / runway / label, then draw with a tool on the left of the map. Polygon or rectangle for an area, circle for the EOR, line for a runway centreline — threshold first. Use New zone when you want another one.

Click a zone in the list (or on the map) to select it — then these fields edit that zone. Nothing is written to disk until you press Save to airports.json.

to

Blank means the area is infinitely tall, which is right for a ramp you only ever taxi on. A tower area wants surface to about 5000 so traffic overhead does not count as being in it.

Zones

The eye next to each zone shows or hides it on the map (list stays). H toggles the selected zone.

    Reference overlay

    View-only airspace / targets from a KML or KMZ (e.g. NTTR). After loading, use the Layers panel on the map (top-right) — nested folders like Opus, with search. These never become zones.
