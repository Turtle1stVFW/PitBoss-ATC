# Crew Chief sound pack (optional)

Default speech is Windows / Google TTS. To use the recorded lines from a
mission (for example `Sounds/CC` inside Mission1.001.miz):

```
py -3 ..\crew_chief_extract.py --miz "C:\path\Mission1.001.miz"
```

Then set **Sound pack** on Setup → Controls.

OGG files in this folder are gitignored. Attribution: Bogey Dope Virtual
Crew Chief voice (not redistributed with this repo).
